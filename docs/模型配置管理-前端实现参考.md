## 2. API 接口封装

```typescript
// src/api/model.ts
import request from '@/utils/request'

export interface ModelConfig {
  id?: number
  name: string
  label: string
  provider: string
  baseUrl: string
  apiKey: string
  model: string
  temperature?: number
  maxTokens?: number
  topP?: number
  jsonResponse?: boolean
  category: string
  enabled?: boolean
  sortOrder?: number
  description?: string
  createTime?: string
  updateTime?: string
}

// 列表查询
export function listModelConfig(category?: string) {
  return request.get<ModelConfig[]>('/model/config', { params: { category } })
}

// 新增
export function createModelConfig(data: ModelConfig) {
  return request.post('/model/config', data)
}

// 编辑
export function updateModelConfig(id: number, data: ModelConfig) {
  return request.put(`/model/config/${id}`, data)
}

// 删除
export function deleteModelConfig(id: number) {
  return request.delete(`/model/config/${id}`)
}

// 测试连接
export function testModelConnection(data: ModelConfig) {
  return request.post('/model/test', data)
}

// 获取供应商列表
export function listModelProviders() {
  return request.get<string[]>('/model/providers')
}
```

## 5. 核心交互流程

| 操作 | 流程 |
|------|------|
| **新增** | 填写表单 → `POST /model/config` → 保存到 DB，下次请求时懒加载创建实例 |
| **编辑** | 修改字段 → `PUT /model/config/{id}` → **后端自动热刷新**：销毁旧实例 → 更新 DB → 下次请求自动创建新实例 |
| **删除** | 点击删除 → `DELETE /model/config/{id}` → 后端移除缓存 + 删除 DB 记录 |
| **测试连接** | 点击测试 → `POST /model/test` → 后端用临时配置创建 ChatModel → 发送 "回复 ok" → 返回响应/错误 |

## 6. provider 切换联动（扩展用）

```typescript
// 当 provider 切换时，显示/隐藏特定字段
watch(() => form.provider, (val) => {
  if (val === 'ollama') {
    // Ollama 不需要 apiKey，不需要 baseUrl（用默认 localhost）
    showApiKey.value = false
    form.baseUrl = 'http://localhost:11434'
  } else {
    showApiKey.value = true
  }
})
```

## 7. 响应数据结构

所有 API 返回统一格式：

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

列表查询返回 `data` 为 `ModelConfig[]`，增/改返回单个对象，删除返回 `null`。

## 8. 供应商扩展对接

以后端 `GET /model/providers` 返回的列表为准，前端下拉框动态渲染，无需硬编码供应商名称。新增供应商（如 `ollama`、`dashscope`）后，后端自动出现在列表中。

## 9. 注意事项

1. **API Key 安全**：前端显示密码框，后端建议加密存储（DB 中的 `api_key` 字段）。
2. **热刷新**：编辑保存后立即生效，无需重启。已缓存的请求继续使用旧实例，新请求使用新实例。
3. **编辑页数据回显**：推荐使用 `GET /model/config/{id}` 查询详情（如果后续增加 detail API），或者通过路由 query 传参。当前设计中列表已包含全量字段，可将选中行数据存入 store 后在新页面读取。
4. **删除防护**：删除主模型前建议检查是否有其他配置依赖此名称。
