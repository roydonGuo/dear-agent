## 1. 接口文档

后端路径前缀（参考现有代理配置）：`/api`，基础 URL 假设为 `http://localhost:8080/api`

### 1.1 通用响应格式

```typescript
interface BaseResult<T> {
  code: number;    // 200=成功, 500=服务端错误
  message: string;
  data: T;
}
```

### 1.2 人设分类 API

#### 获取全部分类列表（无分页）

```
GET /prompt/category/list
```

**Response:**
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1812345678901234561,
      "name": "职场达人",
      "sort": 1,
      "icon": "briefcase",
      "createTime": "2026-05-11T12:00:00",
      "updateTime": "2026-05-11T12:00:00"
    }
  ]
}
```

#### 新增分类

```
POST /prompt/category
Content-Type: application/json

{
  "name": "职场达人",
  "sort": 1,
  "icon": "briefcase"
}
```

#### 查询分类详情

```
GET /prompt/category/{id}
```

#### 编辑分类

```
PUT /prompt/category/{id}
Content-Type: application/json

{
  "name": "职场达人",
  "sort": 2,
  "icon": "briefcase"
}
```

#### 删除分类

```
DELETE /prompt/category/{id}
```

> **注意**：后端未做级联删除，删除分类不会自动删除关联的人设。后续可按需增加。

### 1.3 人设 API

#### 分页查询人设列表

```
GET /prompt/list?pageNum=1&pageSize=10&categoryIds=1,2
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageNum | Integer | 否 | 页码，默认 1 |
| pageSize | Integer | 否 | 每页条数，默认 10 |
| categoryIds | String | 否 | 分类ID过滤，逗号分隔多个ID（OR 逻辑） |

**Response:**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "pageNum": 1,
    "pageSize": 10,
    "total": 25,
    "records": [
      {
        "id": 1812345678901234561,
        "title": "资深 Java 工程师",
        "avatar": "https://example.com/avatar.png",
        "description": "扮演一个经验丰富的 Java 后端开发工程师",
        "prompt": "你现在是一名资深 Java 工程师...",
        "categoryIds": "1,3",
        "createTime": "2026-05-11T12:00:00",
        "updateTime": "2026-05-11T12:00:00"
      }
    ]
  }
}
```

> `prompt` 字段是长文本（longtext），列表页里**不需要展示**，仅在详情或编辑时使用。

#### 新增人设

```
POST /prompt
Content-Type: application/json

{
  "title": "资深 Java 工程师",
  "avatar": "https://example.com/avatar.png",
  "description": "扮演一个经验丰富的 Java 后端开发工程师",
  "prompt": "你现在是一名资深 Java 工程师...",
  "categoryIds": "1,3"
}
```

#### 查询人设详情

```
GET /prompt/{id}
```

#### 编辑人设

```
PUT /prompt/{id}
Content-Type: application/json

{
  "title": "资深 Java 工程师",
  "avatar": "",
  "description": "新的描述",
  "prompt": "新的提示词",
  "categoryIds": "1,2,3"
}
```

> 编辑时**所有字段都要传**（全量更新），缺失的字段会被置空。

#### 删除人设

```
DELETE /prompt/{id}
```

## 2. TypeScript 类型定义

推荐在 `src/types/prompt.ts` 中定义：

```typescript
// ====== 人设分类 ======
export interface AiPromptCategory {
  id: number
  name: string
  sort: number
  icon: string | null
  createTime: string      // ISO datetime
  updateTime: string
}

// 创建/编辑分类时的请求体
export interface AiPromptCategoryRequest {
  name: string
  sort: number
  icon: string | null
}

// ====== 人设 ======
export interface AiPrompt {
  id: number
  title: string
  avatar: string | null
  description: string | null
  prompt: string           // 长文本
  categoryIds: string      // 逗号分隔的分类ID，如 "1,3"
  createTime: string
  updateTime: string
}

// 创建/编辑人设时的请求体
export interface AiPromptRequest {
  title: string
  avatar: string | null
  description: string | null
  prompt: string
  categoryIds: string
}

// ====== 通用分页 ======
export interface PageResult<T> {
  pageNum: number
  pageSize: number
  total: number
  records: T[]
}

// ====== 后端统一响应 ======
export interface BaseResult<T> {
  code: number
  message: string
  data: T
}
```

## 3. API 请求层封装

推荐在 `src/api/prompt.ts` 中统一管理：

```typescript
import request from '@/utils/request'  // 你的 axios 实例
import type {
  BaseResult,
  PageResult,
  AiPrompt,
  AiPromptRequest,
  AiPromptCategory,
  AiPromptCategoryRequest,
} from '@/types/prompt'

// ====== 人设分类 ======
export const getCategoryList = () =>
  request.get<BaseResult<AiPromptCategory[]>>('/prompt/category/list')

export const createCategory = (data: AiPromptCategoryRequest) =>
  request.post<BaseResult<AiPromptCategory>>('/prompt/category', data)

export const getCategoryDetail = (id: number) =>
  request.get<BaseResult<AiPromptCategory>>(`/prompt/category/${id}`)

export const updateCategory = (id: number, data: AiPromptCategoryRequest) =>
  request.put<BaseResult<AiPromptCategory>>(`/prompt/category/${id}`, data)

export const deleteCategory = (id: number) =>
  request.delete<BaseResult<void>>(`/prompt/category/${id}`)

// ====== 人设 ======
export interface PromptListParams {
  pageNum?: number
  pageSize?: number
  categoryIds?: string   // 逗号分隔，如 "1,3"
}

export const getPromptList = (params: PromptListParams) =>
  request.get<BaseResult<PageResult<AiPrompt>>>('/prompt/list', { params })

export const createPrompt = (data: AiPromptRequest) =>
  request.post<BaseResult<AiPrompt>>('/prompt', data)

export const getPromptDetail = (id: number) =>
  request.get<BaseResult<AiPrompt>>(`/prompt/${id}`)

export const updatePrompt = (id: number, data: AiPromptRequest) =>
  request.put<BaseResult<AiPrompt>>(`/prompt/${id}`, data)

export const deletePrompt = (id: number) =>
  request.delete<BaseResult<void>>(`/prompt/${id}`)
```

## 7. 关键交互流程

### 7.1 页面初始化

```
PromptManager mounted()
  ├─ fetchCategoryList()        → GET /prompt/category/list
  ├─ fetchPromptList()          → GET /prompt/list?pageNum=1&pageSize=12
  └─ 渲染 Tabs + 卡片网格
```

### 7.2 按分类筛选

```
用户点击「职场达人」Tab
  ├─ 更新 activeCategoryId = 1
  ├─ 重置 pageNum = 1
  ├─ fetchPromptList(params: { categoryIds: "1" })
  └─ 刷新卡片网格 + 分页
```

### 7.3 新建/编辑人设

```
用户点击「新建」或卡片「编辑」
  ├─ 打开 PromptFormDialog
  ├─ 编辑模式：回填表单数据
  ├─ 用户填写 -> 点击保存
  ├─ POST /prompt (新建) / PUT /prompt/{id} (编辑)
  ├─ 关闭弹窗
  └─ 刷新列表
```

### 7.4 删除人设

```
用户点击卡片「删除」
  ├─ 弹出确认框 "确定删除「xxx」吗？"
  ├─ 用户确认
  ├─ DELETE /prompt/{id}
  ├─ 成功提示
  └─ 刷新列表（如果当前页只有1条且不是第1页，回退 pageNum--）
```

### 7.5 分类 CRUD（弹窗模式）

```
用户点击右上角「分类管理」
  ├─ 打开 CategoryDialog
  ├─ 获取分类列表
  │
  ├─ 添加分类：
  │   ├─ 输入名称、排序、图标
  │   ├─ POST /prompt/category
  │   └─ 刷新分类列表
  │
  ├─ 编辑分类：
  │   ├─ 回填数据
  │   ├─ PUT /prompt/category/{id}
  │   └─ 刷新分类列表
  │
  ├─ 删除分类：
  │   ├─ 确认删除
  │   ├─ DELETE /prompt/category/{id}
  │   └─ 刷新分类列表
  │
  └─ 关闭弹窗 -> 主页面 Tab 更新
```

## 8. 开发建议

### 8.1 推荐技术栈

| 领域 | 推荐方案 |
|------|---------|
| 框架 | Vue 3 + Composition API + `<script setup>` |
| 构建 | Vite |
| UI 库 | Element Plus（国内生态最成熟） |
| HTTP | Axios（已有 request 实例可复用） |
| 类型检查 | TypeScript (strict mode) |
| 路由 | Vue Router 4 |

### 8.2 categoryIds 字段处理

- 后端存储格式为逗号分隔字符串 `"1,3"`
- 分类多选组件（el-checkbox-group）的 `v-model` 用 `number[]`
- **提交前转换**：`[1, 3]` → `"1,3"`
- **回填时转换**：`"1,3"` → `[1, 3]`

示例工具函数：

```typescript
// 将逗号分隔串转为数字数组（用于多选组件回填）
function parseCategoryIds(ids: string): number[] {
  if (!ids) return []
  return ids.split(',').map(Number).filter(Boolean)
}

// 将数字数组转为逗号分隔串（用于提交）
function stringifyCategoryIds(ids: number[]): string {
  return ids.join(',')
}
```

### 8.3 卡片设计要点

卡片推荐的展示字段：

```
┌───────────────────────────┐
│  [avatar 圆头像]           │
│                           │
│  标题 title  (粗体)        │
│                           │
│  描述 description          │
│  (最多显示2行，多余省略)    │
│                           │
│  ────────────────────────  │
│  [使用] [编辑] [删除]      │
└───────────────────────────┘
```

- **avatar** 字段为图片 URL，若为空则显示默认占位图
- **description** 限制最多2行，超出省略号
- **prompt** 内容较长，列表页**不展示**，只在编辑表单中的 textarea 展示
- 「使用」按钮：选中该人设后的业务行为（如填入聊天界面），由你根据产品需求定义

### 8.4 分类图标（icon 字段）

- 后端 `icon` 字段存储的是 **lucide 图标类名**（如 `"briefcase"`, `"heart"`, `"book-open"`）
- 推荐前端使用 `lucide-vue-next` 图标库动态渲染：

```vue
<template>
  <component :is="icons[category.icon]" v-if="category.icon" />
  <FolderOpen v-else />
</template>

<script setup>
import * as icons from 'lucide-vue-next'
</script>
```

### 8.5 卡片布局建议

- 默认 **一页 12 条**（`pageSize=12`）
- 响应式网格：`grid-template-columns: repeat(auto-fill, minmax(260px, 1fr))`
- 移动端适配：小屏改为 1 列，平板 2 列，桌面 4 列

### 8.6 错误处理

```typescript
// 建议统一拦截处理
const handleApiError = (error: unknown) => {
  if (error.response?.data?.message) {
    ElMessage.error(error.response.data.message)
  } else {
    ElMessage.error('操作失败，请重试')
  }
}
```
