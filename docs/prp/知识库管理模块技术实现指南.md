# 知识库管理模块 — Vue 3 前端技术实现指南

## 1. 接口文档


### 1.1 通用响应格式

```typescript
interface BaseResult<T> {
  code: number    // 200=成功, 500=服务端错误
  message: string
  data: T
}
```

### 1.2 知识库分类 API

#### 获取全部分类列表（无分页，按 sort 升序）

```
GET /knowledge/category/list
```

**Response:**
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1812345678901234561, // Long 前端精度会丢失，需要转为string
      "name": "技术文档",
      "sort": 1,
      "icon": "code-2", // lucide类名
      "createTime": "2026-05-14T12:00:00",
      "updateTime": "2026-05-14T12:00:00"
    }
  ]
}
```

> 列表结果已按 `sort` 升序排列。

#### 新增分类

```
POST /knowledge/category
Content-Type: application/json

{
  "name": "技术文档",
  "sort": 1,
  "icon": "code-2"
}
```

**Response:** `BaseResult<KnowledgeCategoryResp>` — 返回新建分类对象（含自动生成 ID）

#### 查询分类详情

```
GET /knowledge/category/{id}
```

**Response:** `BaseResult<KnowledgeCategoryResp>`

#### 编辑分类

```
PUT /knowledge/category/{id}
Content-Type: application/json

{
  "name": "技术文档",
  "sort": 2,
  "icon": "code-2"
}
```

#### 删除分类

```
DELETE /knowledge/category/{id}
```

### 1.3 知识库 API

#### 分页查询知识库列表

```
GET /knowledge/list?pageNum=1&pageSize=12&categoryIds=1,2
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageNum | Integer | 否 | 页码，默认 1 |
| pageSize | Integer | 否 | 每页条数，默认 10 |
| categoryIds | String | 否 | 分类ID过滤，逗号分隔多个ID（FIND_IN_SET OR 逻辑） |

**Response:**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "pageNum": 1,
    "pageSize": 12,
    "total": 25,
    "records": [
      {
        "id": 1812345678901234561, // Long 前端精度会丢失，需要转为string
        "name": "Java 编程规范",
        "description": "团队 Java 编码规范与最佳实践合集",
        "coverPath": "https://minio.example.com/bucket/knowledge/abc123.png",
        "categoryIds": "1,3",
        "createTime": "2026-05-14T12:00:00",
        "updateTime": "2026-05-14T12:00:00"
      }
    ]
  }
}
```

> `coverPath` 字段在服务端已通过 MinIO 重新生成 presigned URL，前端直接使用即可。列表不支持按名称搜索，后续可扩展。

#### 新增知识库

```
POST /knowledge
Content-Type: application/json

{
  "name": "Java 编程规范",
  "description": "团队 Java 编码规范与最佳实践合集",
  "coverPath": "data:image/png;base64,iVBORw0KGgo...", 
  "categoryIds": "1,3"
}
```

> **封面图上传说明**：`coverPath` 支持两种格式：
> - **base64 Data URL**（以 `data:` 开头）：服务端自动上传到 MinIO，存储 MinIO key
> - **已有 URL / 路径**：直接存储原值
>
> 成功后服务端清除列表缓存。

#### 查询知识库详情

```
GET /knowledge/{id}
```

**Response:** `BaseResult<KnowledgeBaseResp>`

> JetCache 两级缓存。coverPath 已在服务端转为 presigned URL。

#### 编辑知识库

```
PUT /knowledge/{id}
Content-Type: application/json

{
  "name": "Java 编程规范 v2",
  "description": "更新后的描述",
  "coverPath": "data:image/png;base64,...",
  "categoryIds": "1,2,3"
}
```

#### 删除知识库

```
DELETE /knowledge/{id}
```

## 2. TypeScript 类型定义

推荐在 `src/types/knowledge.ts` 中定义：

```typescript
// ====== 知识库分类 ======
export interface KnowledgeCategory {
  id: string
  name: string
  sort: number
  icon: string | null
  createTime: string      // ISO datetime
  updateTime: string
}

// 创建/编辑分类时的请求体
export interface KnowledgeCategoryRequest {
  name: string
  sort: number
  icon: string | null
}

// ====== 知识库 ======
export interface KnowledgeBase {
  id: string
  name: string
  description: string | null
  coverPath: string | null   // presigned URL（服务端已处理），可直接用于 <img src>
  categoryIds: string        // 逗号分隔的分类ID，如 "1,3"
  createTime: string
  updateTime: string
}

// 创建/编辑知识库时的请求体
export interface KnowledgeBaseRequest {
  name: string
  description: string | null
  coverPath: string | null   // base64 data URL 或已有路径
  categoryIds: string        // 逗号分隔
}

// ====== 通用分页 后端统一响应 均已定义 ====== 
```

## 3. API 请求层封装

推荐在 `src/api/knowledge.ts` 中统一管理：

```typescript
import request from '@/utils/request'  // 你的 axios 实例
import type {
  BaseResult,
  PageResult,
  KnowledgeBase,
  KnowledgeBaseRequest,
  KnowledgeCategory,
  KnowledgeCategoryRequest,
} from '@/types/knowledge'

// ====== 知识库分类 ======
export const getCategoryList = () =>
  request.get<BaseResult<KnowledgeCategory[]>>('/knowledge/category/list')

export const createCategory = (data: KnowledgeCategoryRequest) =>
  request.post<BaseResult<KnowledgeCategory>>('/knowledge/category', data)

export const getCategoryDetail = (id: number) =>
  request.get<BaseResult<KnowledgeCategory>>(`/knowledge/category/${id}`)

export const updateCategory = (id: number, data: KnowledgeCategoryRequest) =>
  request.put<BaseResult<KnowledgeCategory>>(`/knowledge/category/${id}`, data)

export const deleteCategory = (id: number) =>
  request.delete<BaseResult<void>>(`/knowledge/category/${id}`)

// ====== 知识库 ======
export interface KnowledgeListParams {
  pageNum?: number
  pageSize?: number
  categoryIds?: string   // 逗号分隔，如 "1,3"
}

export const getKnowledgeList = (params: KnowledgeListParams) =>
  request.get<BaseResult<PageResult<KnowledgeBase>>>('/knowledge/list', { params })

export const createKnowledge = (data: KnowledgeBaseRequest) =>
  request.post<BaseResult<KnowledgeBase>>('/knowledge', data)

export const getKnowledgeDetail = (id: number) =>
  request.get<BaseResult<KnowledgeBase>>(`/knowledge/${id}`)

export const updateKnowledge = (id: number, data: KnowledgeBaseRequest) =>
  request.put<BaseResult<KnowledgeBase>>(`/knowledge/${id}`, data)

export const deleteKnowledge = (id: number) =>
  request.delete<BaseResult<void>>(`/knowledge/${id}`)
```

**页面布局要点：**

1. **标题栏**：左侧"知识库管理"标题以及小子介绍，右侧「分类管理」按钮
2. **分类筛选 Tabs**：首项"全部"（不传 `categoryIds`），后续 Tab 来自分类列表 API，点击切换时传入对应 `categoryIds`
3. **卡片网格**：每个卡片展示知识库的**封面图**、**名称**、**描述**和**所属分类标签**，和创建时间，和文档数量，右下角hover后展示更多图标（弹出menu：编辑、删除）
4. **新建按钮**：固定在卡片网格右上方
5. **触底加载更多**：滑动到底部后自动加载更多

### 4.4 知识库编辑表单（KnowledgeFormDialog.vue）

新建和编辑复用同一表单：

```
┌──────────────────────────────────┐
│  新建知识库 / 编辑知识库     [×]  │
│  ───────────────────────────────  │
│                                   │
│  封面:                         │
│  ┌───────────────────────────┐    │
│  │             预览           │    │  ← 图片上传区域
│  │            ＋              │   │
│  └───────────────────────────┘    │
│                                   │
│  名称:      [________________]    │  ← 必填，最多20字符
│  分类:  [☑ 技术文档 ☑ 产品...] │  ← 多选（解析 categoryIds）
│  描述:      [________________]    │  ← textarea，最多500字符
│             [________________]    │
│                                   │
│              [取消]  [保  存]      │
└──────────────────────────────────┘
```

> **封面图交互说明**：
> - 点击上传区域 → 打开文件选择器（accept="image/*"）
> - 选择文件后 → `FileReader` 转为 base64 Data URL，预览显示
> - 提交时 `coverPath` 传 base64 字符串，服务端自动上传 MinIO
> - 编辑回填时，`coverPath` 已是完整 URL，直接用于预览 `<img>`
> - 如果用户未更换封面，提交时传回原来的值（非 base64 的 URL 路径原样存储）
