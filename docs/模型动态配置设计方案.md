# 模型动态配置管理设计方案

## 1. 目标

- 将模型的 `model`、`temperature`、`base-url`、`api-key` 等配置从 `application.yml` 硬编码**抽离到数据库**
- 支持多种**模型供应商**（OpenAI 兼容、DashScope、Ollama 等），可插拔扩展
- 通过**前端管理界面**增删改查模型配置，**运行时切换**，无需重启
- Agent 和 TTS 服务通过**注册中心**按需获取模型实例

---

## 2. 现状分析

当前模型配置在 `application.yml` 中硬编码：

```yaml
spring:
  ai:
    openai:
      api-key: @dashscope.api.key@
      base-url: https://dashscope.aliyuncs.com/compatible-mode/
      chat:
        options:
          model: glm-5
          temperature: 0.7
          maxTokens: 50000
```

使用方通过 `@Autowired ChatModel chatModel` 直接注入 Spring Boot 自动配置的单例 Bean，**无法运行时切换**。

涉及的使用点：

| 类 | 注入方式 | 用途 |
|------|----------|------|
| `AgentController` | `@Autowired ChatModel` | 传给 DearAgent 构造函数 |
| `RealtimeVoiceAgentService` | `@Autowired OpenAiChatModel` | 直接构建 ChatClient |
| `BaseAgent.generateRecommendations()` | `ChatClient.builder(chatModel)` | 推荐问题生成 |
| 所有 Agent 构造函数 | 透传 ChatModel 参数 | 构建 ChatClient |

### 5.2 ModelProvider 接口（供应商扩展点）

```java
/**
 * 模型供应商接口
 * 新增供应商只需实现此接口，注册为 Spring Bean @Component
 * SPI / @Component 自动发现
 */
public interface ModelProvider {

    /** 供应商标识，如 "openai"、"ollama" */
    String getProviderName();

    /** 根据配置创建 ChatModel */
    ChatModel createChatModel(ModelConfig config);

    /** 是否支持此供应商 */
    default boolean supports(String provider) {
        return getProviderName().equals(provider);
    }
}
```

### 5.3 OpenAiModelProvider（OpenAI 兼容实现）

```java
@Component
public class OpenAiModelProvider implements ModelProvider {

    @Override
    public String getProviderName() {
        return "openai";
    }

    @Override
    public ChatModel createChatModel(ModelConfig config) {
        OpenAiChatOptions options = OpenAiChatOptions.builder()
                .model(config.getModel())
                .temperature(config.getTemperature() != null ? config.getTemperature().floatValue() : null)
                .maxTokens(config.getMaxTokens())
                .topP(config.getTopP() != null ? config.getTopP().floatValue() : null)
                .build();

        return OpenAiChatModel.builder()
                .apiKey(config.getApiKey())
                .baseUrl(config.getBaseUrl())
                .defaultOptions(options)
                .build();
    }
}
```

### 5.4 ModelRegistry（核心注册中心）

```java
@Slf4j
@Component
public class ModelRegistry implements InitializingBean, DisposableBean {

    /** name -> ChatModel 实例的缓存 */
    private final Map<String, ChatModel> chatModelCache = new ConcurrentHashMap<>();
    /** category -> 默认模型的 name */
    private final Map<String, String> defaultModelNames = new ConcurrentHashMap<>();

    @Autowired
    private List<ModelProvider> providers;

    @Autowired
    private ModelConfigService configService;

    @Override
    public void afterPropertiesSet() {
        // 启动时加载默认配置映射，不实例化 ChatModel（懒加载）
        List<ModelConfig> enabledConfigs = configService.listEnabled();
        for (ModelConfig cfg : enabledConfigs) {
            defaultModelNames.putIfAbsent(cfg.getCategory(), cfg.getName());
            log.debug("模型配置就绪: {} ({})", cfg.getName(), cfg.getCategory());
        }
        log.info("ModelRegistry 初始化完成, 共 {} 条模型配置", enabledConfigs.size());
    }

    /**
     * 获取指定名称的 ChatModel（懒加载）
     */
    public ChatModel getChatModel(String name) {
        return chatModelCache.computeIfAbsent(name, this::createChatModel);
    }

    /**
     * 获取指定分类的默认 ChatModel
     */
    public ChatModel getDefaultChatModel(String category) {
        String name = defaultModelNames.get(category);
        if (name == null) {
            throw new IllegalArgumentException("没有找到 " + category + " 类型的默认模型");
        }
        return getChatModel(name);
    }

    /**
     * 刷新指定模型配置
     */
    public synchronized void refresh(Long configId) {
        ModelConfig cfg = configService.getById(configId);
        if (cfg == null) throw new IllegalArgumentException("模型配置不存在: " + configId);
        // 关闭旧实例
        ChatModel old = chatModelCache.remove(cfg.getName());
        if (old instanceof DisposableBean bean) {
            try { bean.destroy(); } catch (Exception ignored) {}
        }
        if (cfg.getEnabled()) {
            defaultModelNames.put(cfg.getCategory(), cfg.getName());
        } else {
            defaultModelNames.remove(cfg.getCategory());
        }
        log.info("模型配置已刷新: {}", cfg.getName());
    }

    /**
     * 找到支持的供应商
     */
    private ChatModel createChatModel(String name) {
        ModelConfig cfg = configService.getByName(name);
        if (cfg == null) throw new IllegalArgumentException("模型配置不存在: " + name);

        ModelProvider provider = providers.stream()
                .filter(p -> p.supports(cfg.getProvider()))
                .findFirst()
                .orElseThrow(() -> new IllegalArgumentException("不支持的供应商: " + cfg.getProvider()));

        log.info("创建 ChatModel 实例: {} (provider={}, model={})",
                name, cfg.getProvider(), cfg.getModel());
        return provider.createChatModel(cfg);
    }

    @Override
    public void destroy() {
        chatModelCache.values().forEach(cm -> {
            if (cm instanceof DisposableBean bean) {
                try { bean.destroy(); } catch (Exception ignored) {}
            }
        });
        chatModelCache.clear();
    }
}
```

### 5.5 ModelAdminController

```java
@Slf4j
@RestController
@RequestMapping("/admin/model")
@RequiredArgsConstructor
public class ModelAdminController {

    private final ModelConfigService configService;
    private final ModelRegistry registry;
    private final List<ModelProvider> providers;

    // 6.1 配置列表
    @GetMapping("/config")
    public BaseResult<List<ModelConfig>> list(
            @RequestParam(required = false) String category) {
        List<ModelConfig> list = category != null
                ? configService.listByCategory(category)
                : configService.listAllOrdered();
        return BaseResult.newSuccess(list);
    }

    // 6.2 新增
    @PostMapping("/config")
    @Transactional(rollbackFor = Exception.class)
    public BaseResult<ModelConfig> create(@Valid @RequestBody ModelConfig cfg) {
        cfg.setId(null);
        // 验证供应商
        validateProvider(cfg);
        configService.save(cfg);
        return BaseResult.newSuccess(cfg);
    }

    // 6.3 编辑 + 热刷新
    @PutMapping("/config/{id}")
    @Transactional(rollbackFor = Exception.class)
    public BaseResult<ModelConfig> update(@PathVariable Long id,
                                            @Valid @RequestBody ModelConfig cfg) {
        cfg.setId(id);
        validateProvider(cfg);
        configService.updateById(cfg);
        registry.refresh(id);  // 热刷新 ChatModel
        return BaseResult.newSuccess(cfg);
    }

    // 6.4 删除
    @DeleteMapping("/config/{id}")
    @Transactional(rollbackFor = Exception.class)
    public BaseResult<Void> delete(@PathVariable Long id) {
        ModelConfig cfg = configService.getById(id);
        if (cfg == null) return BaseResult.newError("配置不存在");
        registry.refresh(id);  // 关闭并移除
        configService.removeById(id);
        return BaseResult.newSuccess();
    }

    // 6.5 测试连接
    @PostMapping("/test")
    public BaseResult<String> testConnection(@Valid @RequestBody ModelConfig cfg) {
        try {
            ModelProvider provider = providers.stream()
                    .filter(p -> p.supports(cfg.getProvider()))
                    .findFirst()
                    .orElseThrow(() -> new IllegalArgumentException("不支持的供应商"));

            ChatModel chatModel = provider.createChatModel(cfg);
            String resp = ChatClient.builder(chatModel).build()
                    .prompt().user("返回 ok 即可").call().content();
            return BaseResult.newSuccess("连接成功, 模型响应: " + resp);
        } catch (Exception e) {
            return BaseResult.newError("连接失败: " + e.getMessage());
        }
    }

    // 6.6 获取支持供应商列表
    @GetMapping("/providers")
    public BaseResult<List<String>> listProviders() {
        return BaseResult.newSuccess(
                providers.stream().map(ModelProvider::getProviderName).collect(Collectors.toList()));
    }

    private void validateProvider(ModelConfig cfg) {
        boolean supported = providers.stream().anyMatch(p -> p.supports(cfg.getProvider()));
        if (!supported) {
            throw new IllegalArgumentException(
                    "不支持的供应商: " + cfg.getProvider() + "，可用: "
                    + providers.stream().map(ModelProvider::getProviderName).collect(Collectors.joining(", ")));
        }
    }
}
```

## 9. 与现有配置的关系

### 9.1 兼容策略

改造期间暂时**保留** `application.yml` 中的 `spring.ai.openai.*` 配置。引入 `ModelRegistry` 后：

1. 如果 DB 中没有 `model_config` 数据 → 回退使用 `application.yml` 中的 `ChatModel` Bean
2. 如果 DB 中有已启用的配置 → 优先使用 `ModelRegistry` 创建的模型

### 9.2 启用标记

可通过配置开关 `app.model.use-database-config: true` 控制是否启用数据库配置模式。但建议直接迁移，去掉回退逻辑以简化架构。

## 11. 设计要点总结

| 要点 | 说明 |
|------|------|
| **懒加载** | 启动时不创建 ChatModel 实例，首次 `getChatModel()` 时才创建 |
| **热切换** | 前端修改配置 → `registry.refresh(id)` → 销毁旧实例 → 下次请求自动创建新实例 |
| **扩展性** | 新增供应商只需添加 `@Component` 实现 `ModelProvider` 接口，零侵入 |
| **缓存隔离** | `ConcurrentHashMap` 缓存 ChatModel，refresh 时 remove 旧 key |
| **回退兼容** | 初期可保留原有 `application.yml` 的 ChatModel Bean 作为回退 |
| **对齐 MCP 设计** | 与 McpRegistry 使用完全一致的设计模式：懒加载 + refresh + destroy |
